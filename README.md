# Portfolio Control Room

Private internal control room for the full product estate.

## Purpose

This repository is the canonical internal overview for products, markets, repositories, deployments, domains, migration status, architecture references and operational follow-up.

It must **not** become a shared runtime monolith. Product application code remains in each dedicated repository.

## Current structure

- Australia: SentrixDigital AU, AU Compass, ClaimThread, RentReady VIC
- South Africa / RiskAtlas: RiskAtlas, ClinicalAtlas ZA, SchemeBook, Compass ZA, Demand Desk, RiskAtlas Tools
- Claims: ClaimHub / ClaimBuddy
- Independent / experimental products: tracked separately

## Security

This repository is intended to be private before operational details, credentials, secrets or sensitive architecture material are added.
